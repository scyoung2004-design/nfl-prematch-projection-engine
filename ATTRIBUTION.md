# Attribution

This independent educational portfolio project uses public historical NFL data hosted by:

- NityaGehlot/nfl-data: https://github.com/NityaGehlot/nfl-data
- nflverse/nflverse-data: https://github.com/nflverse/nflverse-data

The source repository documents that its weekly player-stat pipeline uses nflreadr / nflverse data.

PrizePicks public help pages are referenced only to explain the general public-facing concept of player-stat projections and More/Less selections. No proprietary PrizePicks data, source code, internal methodology, or member data is used.
